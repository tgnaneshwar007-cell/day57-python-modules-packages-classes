## 💡 Key Learnings

* Modules allow Python functionality to be reused.
* The `math` module provides mathematical functions.
* The `time` module provides time-related functionality.
* `time.sleep()` can pause program execution.
* Packages help organize related Python modules.
* A class acts as a blueprint for creating objects.
* Objects can access attributes and methods defined in a class.
